# 📊 React Admin Dashboard

A modern, responsive Admin Dashboard built with **React.js** and **Bootstrap**. This project demonstrates my ability to build dynamic user interfaces, manage state effectively, and visualize data using charts.

## 🚀 Live Demo
👉 **[Click Here to View Live Demo](https://admin-panel-nine-orpin.vercel.app/)**

## ✨ Key Features

* **Responsive Design:** Fully responsive layout that works on Desktop, Tablet, and Mobile using Bootstrap 5.
* **Dark/Light Mode:** Seamless theme switching with state persistence.
* **Interactive Charts:** Data visualization using **Recharts** (Line & Bar charts).
* **Routing:** fast navigation between pages (Dashboard, Users, Orders, Settings) using **React Router v6**.
* **State Management:** Efficient state handling for sidebar toggling and theme preferences.
* **Clean UI/UX:** Modern icons using **Lucide React** and a clean, organized layout.

## 🛠️ Tech Stack

* **Frontend:** React.js (Hooks, Functional Components)
* **Styling:** Bootstrap 5, CSS3, Responsive Design
* **Routing:** React Router DOM
* **Icons:** Lucide React
* **Charts:** Recharts
* **Deployment:** Vercel (Recommended)

## 💻 Getting Started

To run this project locally on your machine, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/majdharb123/admin-panel.git](https://github.com/majdharb123/admin-panel.git)
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd admin-panel
    ```

3.  **Install dependencies:**
    ```bash
    npm install
    ```

4.  **Start the development server:**
    ```bash
    npm start
    ```

The app will open in your browser at `http://localhost:3000`.
